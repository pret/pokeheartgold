# Pokémon HeartGold and SoulSilver

This is a WIP disassembly of Pokémon HeartGold and SoulSilver. For instructions on how to set up the repository, please read [INSTALL.md](INSTALL.md).

> ![WARN]
> This repository is in an unstable, work-in-progress state. Symbol names and code structure can change drastically and without warning. If you are using this as a base for your own mods, you accept all the associated risks.

> ![WARN]
> Because this ROM is not fully decompiled, modifications that affect the size or layout of any function or data structure can result in a game crash.
