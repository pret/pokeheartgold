11/*
12 Init Script Type: INIT_SCRIPT_ON_FRAME_TABLE
13 Before each frame of input processing, a table of conditions for the map is checked.
14 Runs the first script where its two condition variables are equal.

16 The first check only occurs after all other init script types have run.
